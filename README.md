# saltmere.github.io
Saltmere — Ders değil, dizi. İngilizce polisiye uygulamasının tanıtım sitesi.

- Bağımlılık yok: `index.html`, `styles.css`, `app.js`. Yazı tipleri `fonts/` altında (SIL OFL, Latin + Türkçe alt küme).
- Görseller ve klipler uygulamanın kendi sahnelerinden (`img/`, `medya/`), sesler uygulamadaki karakter seslerinden (`ses/`).
- Mağaza bağlantıları: `app.js` başındaki `STORE` nesnesine adresi yazınca "Yakında" etiketleri kendiliğinden kalkar.
- Hareketi azalt açıkken bütün döngüler ve 3D eğilme kapalıdır; içerik JS olmadan da tam görünür.
